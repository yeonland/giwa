# 기와 (Giwa) — 문화유산 읽는 법

한 장씩 쌓는 문화유산 / Korean Heritage, One Tile at a Time

현장에서 보이는 단서(구조, 부재, 지물, 형태)로 문화유산을 알아보는 법을 알려주는 도해 중심 용어 서비스. 첫 편은 남해안 성곽.

## 왜 만들었나

남자친구, 외국인 친구와 경주 불국사·첨성대에 갔을 때 두 사람이 똑같이 물었습니다. "저건 뭐야?" 깊은 역사가 궁금한 게 아니라, 눈앞에 있는 게 무엇이고 무엇에 쓰였는지가 궁금했던 겁니다. 안내판은 그 질문에 바로 답해 주지 못했고, 영어 설명은 거의 없었습니다.

문화유산을 찾는 사람 중 역사를 좋아하는 사람은 일부이고, 많은 사람은 함께 따라오거나 여행 코스라서 들릅니다. 기와는 **역사에 관심이 적은 사람도 "아, 그래서!" 하고 이해할 수 있게** 문화유산을 쉽고 재밌게 풀어 주는 서비스입니다.

- 첫 화면은 "저건 뭐야?"에 대한 한 줄 답 (예: 치 — 성벽에서 튀어나온 부분. 다가오는 적을 옆에서 공격하려고 만들었어요)
- 연도나 한자보다 "왜 이렇게 생겼는지"를 먼저
- 더 궁금한 사람만 용어 카드로 들어가 현장에서 알아보는 법을 확인
- 한 줄 설명이라 영어로도 함께 제공

문화재 조사 현장에서 이런 용어를 매일 썼던 경험을, 관심 없는 사람의 눈높이로 옮기는 것이 목표입니다.

## 왜 남해안 성곽부터인가

용어 설명은 출처가 정확해야 합니다. 그래서 체계적으로 정리된 참고 자료가 있는 남해안 성곽을 첫 편으로 정했습니다. 용어마다 출처를 붙이고, 원문을 그대로 옮기지 않고 풀어 씁니다.

## 지금 상태

프로토타입: 진성 평면도(SVG)에서 시설을 누르면 용어 카드가 열리는 화면 1개.

- 용어 5개: 체성, 치, 옹성, 해자, 여장
- 카드: 명칭, 한자, 이칭, 뜻, 알아보는 법, 관련 용어(누르면 그 카드로), 출처
- 검색: 한글·영어·한자·이칭으로 찾기
- 한국어 / 영어 전환
- 키보드로도 도해 부재 선택 가능 (Tab → Enter)

## 실행

`index.html`을 브라우저로 열면 된다. 설치·빌드 없음.

## 사용 기술

| 기술 | 어디에 | 왜 |
|------|--------|-----|
| HTML | 화면 구조 (`index.html`) | 프로토타입 단계라 빌드 도구 없이 바로 열려야 해서 |
| SVG | 진성 평면도 | 확대해도 깨지지 않고, 부재마다 누를 수 있게 나눌 수 있어서. 지금은 임시 도형, 직접 그린 도해로 바꿀 예정 |
| CSS (BEM) | `index.html`의 `<style>` | 클래스 이름만 보고 어느 블록의 어느 부분인지 알 수 있게 |
| CSS 변수 | 색 (`--tile` 기와색 등) | 색을 한 곳에서 바꾸려고 |
| CSS Grid + 미디어 쿼리 | 도해·카드 배치 | 휴대폰은 위아래, 800px 이상은 좌우 |
| JavaScript (라이브러리 없음) | 카드 그리기, 검색, 언어 전환 | 기능이 작아서 |
| JSON 형식 데이터 | `data.js` | 나중에 노션에서 내보낸 데이터로 바꾸기 쉽게. `file://`로 열면 `fetch`가 막혀서 `.js`로 감쌈 |

## 코드 구조

```
giwa/
├─ index.html      화면: 마크업 + <style> + <script>
├─ data.js         용어 카드 데이터 (window.TERMS)
└─ docs/
   └─ 코드규칙.md   HTML·CSS(BEM)·JS·데이터 규칙
```

`index.html` 안의 흐름:

1. **화면 글 사전 `UI`**: 한국어·영어 문구. `data-i18n="이름"`이 붙은 곳에 들어간다.
2. **`byId`**: 카드를 id로 바로 찾는 표. 만들 때 관계 대상이 없는 카드가 있으면 콘솔에 경고.
3. **`show(id)`**: 고른 카드를 기억하고, 도해에서 그 부재에 `plan__part--active`를 붙인 뒤 `render()`.
4. **`render()`**: 지금 언어로 화면 글·카드를 다시 그린다. 데이터 글은 `esc()`로 감싸서 HTML로 해석되지 않게 한다.
5. **`search(q)`**: 제목·한자·이칭에서 찾아 결과 버튼 목록을 그린다.
6. **이벤트**: `document` 한 곳에서 클릭·Enter·Space를 받아 `data-id`(도해 부재) 또는 `data-go`(검색 결과·관련 용어)를 읽고 `show()`.

도해를 직접 그린 SVG로 바꿀 때는 부재마다 `<g class="plan__part" data-id="카드id" tabindex="0" role="button">`만 지키면 된다.

## 코드 규칙

[docs/코드규칙.md](docs/코드규칙.md) 요약:

- **CSS는 BEM**: `블록__요소--수정자` (예: `card__title`, `plan__part--active`). `#id`·태그 선택자 안 씀
- **클래스는 CSS 전용, JS는 `id`와 `data-*`로** 요소를 찾음
- 데이터 글은 `esc()` 후 `innerHTML`, 화면 글은 `UI` 사전에
- 데이터는 언어별 필드(`ko`/`en`), id는 `엔티티-로마자`, 모든 카드에 출처
