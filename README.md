# 기와 (Giwa) — 문화유산 읽는 법

한 장씩 쌓는 문화유산 / Korean Heritage, One Tile at a Time

현장에서 보이는 단서(구조, 부재, 지물, 형태)로 문화유산을 알아보는 법을 알려주는 도해 중심 용어 서비스. 첫 편은 남해안 성곽.

## 지금 상태

프로토타입: 진성 평면도(SVG)에서 시설을 누르면 용어 카드가 열리는 화면 1개. 용어 5개(체성, 치, 옹성, 해자, 여장), 한국어·영어 전환.

## 실행

`index.html`을 브라우저로 열면 됨. 카드 데이터는 `data.js`.
